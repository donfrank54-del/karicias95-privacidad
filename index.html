Política de privacidad de Karicias95.com

Última actualización: 20 de octubre de 2026

1. Introducción

Karicias95.com ofrece una aplicación móvil para escuchar nuestra emisora de radio por internet. Respetamos la privacidad de nuestros oyentes y procuramos limitar el tratamiento de datos a lo necesario para prestar el servicio.

2. Información recopilada por la aplicación

La aplicación no requiere crear una cuenta y no incluye formularios para registrar información personal. Según las funciones actualmente disponibles, no utilizamos la aplicación para mostrar publicidad personalizada ni para realizar seguimiento publicitario o análisis del comportamiento de los usuarios.

3. Datos técnicos de la transmisión

Para reproducir la señal de radio, el dispositivo se conecta a servicios de transmisión por internet. El proveedor de transmisión o los proveedores de infraestructura podrían procesar información técnica, como direcciones IP, fecha y hora de conexión y registros de solicitudes, para entregar la señal, mantener la seguridad y resolver problemas técnicos. La conservación y el uso de esos registros dependen de los proveedores correspondientes.

4. Compartición de información

No vendemos información personal de los usuarios. Los proveedores tecnológicos necesarios para operar la transmisión pueden procesar datos técnicos conforme a sus funciones y políticas aplicables.

5. Conservación y eliminación de datos

La aplicación no mantiene cuentas de usuario ni ofrece una función para almacenar perfiles personales. Los registros técnicos que pudieran generar los proveedores se conservan y eliminan de acuerdo con sus políticas y necesidades operativas. Para consultas relacionadas con privacidad, puede escribirnos al correo indicado al final de esta política.

6. Privacidad de menores

La aplicación está destinada a una audiencia general y no solicita deliberadamente información personal de menores mediante cuentas o formularios.

7. Seguridad

Tomamos medidas razonables para mantener el servicio funcionando de manera segura. Ningún método de transmisión electrónica puede garantizar seguridad absoluta.

8. Cambios en esta política

Podemos actualizar esta política si cambian las funciones de la aplicación, los proveedores tecnológicos o los requisitos legales. La versión vigente estará disponible en esta página.
